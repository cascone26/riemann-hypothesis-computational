# Hodge-Index Signature Transport via q→1 Limit

**Task (from S2659):** Investigate whether the Hodge-index signature (a discrete integer invariant, specifically "exactly one negative direction") can survive the q→1 limit when applied to function fields over F_q, thereby providing a plausible bridge to the arithmetic case (actual ζ).

**Status:** ACTIVE (2026-09-16, ~23:10 CDT)

## 1. The Obstruction Being Attacked

**Classical result (Weil, 1940s):** For a curve C over F_q, the function-field analog of RH is *proven* via:
- Arithmetic Hodge-index theorem on Picard(C ⊗ C)
- Intersection form on NS(C × C) has signature (1, ρ-1) where ρ = rank NS
- This signature directly forces all zeros of the L-function to lie on Re(s)=1/2

**The transport problem:** Number-field case (actual ζ) would require an analogous object on "Spec Z ⊗_F1 Spec Z" (F1 = field with one element), which doesn't exist as a genuine scheme.

**Key observation (prior LEDGER context):**
- A rigorous q→1 limit EXISTS for L-functions themselves (Kurokawa's absolute tensor product, Connes-Consani, Soulé)
- But whether the SIGNATURE (a discrete integer) survives that limit was found to be UNEXPLORED in the literature
- Precise identified obstruction: Spec Z is 1-dimensional, so no room for a literal (1,n-1) signature in the naive sense

**Our approach:** Instead of demanding a literal 2D object exist, ask whether the SIGNATURE INFORMATION ITSELF can be tracked through a DEFORMATION using genuinely 2D objects (families of curves C_q) as q varies.

### Phase 2: Toy Computation
**Goal:** Compute signature explicitly for a simple family of curves over F_q as q varies.

**Test case: Elliptic curves over F_q**

For an elliptic curve E over F_q:
- E ≅ P^1 (rationally) but NOT as schemes — algebraic structure rich
- Picard(E) ≅ E (self-dual)
- NS(E × E) is rank ≥ 3 (diagonal, anti-diagonal, ℓ × ℓ for any ℓ ∈ End(E))
- Hodge-index: signature (1, rank-1) by Weil

**Explicit test:** 
- Fix a minimal model E over Z with good reduction at p
- Reduce mod p: E_p over F_p
- Compute NS(E_p × E_p) intersection form signature for p = 2,3,5,7,...,97 (small primes)
- Track how the signature stabilizes (should be (1, rank-1) for all p)
- Now: take a SEQUENCE p_k → ∞ (scaling toward "q→1 limit" in a heuristic sense)
- Does the rank stabilize? Does the signature change?

**Even simpler:** P^1 over F_q
- E = P^1 over F_q
- E × E ≅ P^2 over F_q
- NS(P^2) ≅ Z (generated by a line), rank = 1, signature trivially (1,0)
- This doesn't help because rank = 1 trivially

**Better: Hyperelliptic curve** y² = x^5 + 1 over F_q
- Genus g = 2, rank of Pic grows with q
- Jacobian Jac(C) = principally polarized abelian surface
- As q varies, Jac's Picard rank can vary, but the principal polarization gives structure
