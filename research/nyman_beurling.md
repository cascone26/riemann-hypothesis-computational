## 1. The Nyman-Beurling Criterion

### History

- **Nyman (1950)**: Bertil Nyman proved the original equivalence in his PhD thesis.
- **Beurling (1955)**: Arne Beurling generalized it to L^p spaces.
- **Baez-Duarte (2002-2005)**: Luis Baez-Duarte strengthened the criterion by restricting parameters to integers.
- **Burnol (2002)**: Jean-Francois Burnol provided quantitative refinements connecting the distance to off-critical-line zeros.
- **Bagchi (2006)**: Bhaskar Bagchi wrote the definitive survey disentangling the various formulations.

### The Exact Statement

Let rho(x) = {x} = x - floor(x) be the fractional part function. Define the **Beurling subspace** B as the set of all functions of the form:

```
f(t) = sum_{k=1}^{n} c_k * rho(theta_k / t)
```

where n is any positive integer, c_k are complex numbers, and 0 < theta_k <= 1.

Let chi = chi_{(0,1]} be the characteristic (indicator) function of the interval (0,1].

**Theorem (Nyman-Beurling):** The Riemann Hypothesis is true if and only if

```
chi is in the L^2(0,1) closure of B
```

Equivalently, RH holds iff d(chi, B) = 0, where d denotes the L^2 distance.

### Beurling's Generalization

**Theorem (Beurling, 1955):** The Riemann zeta function has no zeros with Re(s) > 1/p if and only if B is dense in L^p(0,1).

The case p = 2 gives the classical Nyman-Beurling criterion (no zeros with Re(s) > 1/2, i.e., RH).

### Why This Works (Intuition)

The fractional part function {theta/t} encodes arithmetic information about divisibility. The Mellin transform maps L^2(0,1) unitarily onto the Hardy class H^2 in the half-plane Re(s) > 1/2. Under this transform, the density question becomes a question about the zeros of zeta(s) in that half-plane. The Mellin transform of rho(theta/t) involves zeta(s), and the closure properties of the span are controlled by whether zeta has zeros off the critical line.

## 2. Baez-Duarte's Reformulation

### The Strengthening

The original Nyman-Beurling criterion allows theta_k to be any real numbers in (0,1]. Baez-Duarte conjectured (and later proved) that one can restrict to theta_k = 1/k for positive integers k:

Define the **natural Beurling subspace** B_nat as the set of all functions:

```
f(t) = sum_{k=1}^{n} c_k * rho(1/(k*t))
```

where k ranges over positive integers.

**Theorem (Baez-Duarte, 2002):** The Riemann Hypothesis is true if and only if chi is in the L^2 closure of B_nat.

### Why This Is More Tractable

1. **Countable vs. uncountable**: B_nat is generated by a countable set of functions (indexed by positive integers), while B uses an uncountable parameter space. This makes the problem more combinatorial and amenable to computation.

2. **Dirichlet polynomial formulation**: The density problem translates to: RH holds iff

```
lim_{N -> infinity} d_N^2 = 0
```

where:

```
d_N^2 = inf_{A_N} (1/(2*pi)) * integral_{-inf}^{inf} |1 - zeta(A_N(1/2 + it))|^2 / (1/4 + t^2) dt
```

and the infimum is over all **Dirichlet polynomials** A_N(s) = sum_{n=1}^{N} a_n / n^s of length N.

3. **Sequence space formulation (Bagchi)**: The problem can be reformulated in l^2(N) with a weighted inner product, where RH holds iff a specific constant sequence lies in the closure of the span of a Beurling sequence. This is a pure linear algebra / Hilbert space problem.

### The Key Quantity: d_N^2

The distance d_N^2 measures how well the characteristic function chi_{(0,1]} can be approximated by Dirichlet polynomials of length N acting on the zeta function. RH is equivalent to d_N^2 -> 0 as N -> infinity.

## 3. Computational Approaches

### Landreau-Richard Computations (2002)

The paper "Le critere de Beurling et Nyman pour l'hypothese de Riemann: aspects numeriques" (Experimental Mathematics, 2002) is the key computational reference.

**Methods used:**
- Gram-Schmidt orthonormalization (Gram determinant calculations are too expensive)
- Computed d_N for N up to 20,000
- Tabulated optimal theta values (both real-valued and restricted to reciprocals of integers)

**Key findings:**
- d_N decreases as N increases, consistent with RH
- The decrease is extremely slow (logarithmic)
- Tables of optimal theta_i values for small N (both as reciprocals of integers and as rationals)

### Convergence Rate Bounds

**Lower bound (unconditional, Baez-Duarte et al.):**

```
d_N^2 >= C / log(N)   for large N
```

where:

```
C = sum_{rho: Re(rho)=1/2} 1/|rho|^2
```

summing over distinct zeros on the critical line. This constant involves ALL the nontrivial zeros.

**Burnol's matching lower bound:** Burnol independently proved d_N^2 >= C + o(1) / log(N) for the same constant C, establishing the sharpness of this lower bound.

**Expected asymptotic (conditional on RH):**

```
d_N^2 ~ (1/log(N)) * sum_{rho: Re(rho)=1/2} m(rho)^2 / |rho|^2
```

where m(rho) is the multiplicity of the zero rho. (If all zeros are simple, m(rho) = 1 and this coincides with the lower bound.)

### Bettin-Conrey-Farmer (2012)

"An optimal choice of Dirichlet polynomials for the Nyman-Beurling criterion"

**Key results:**
- Identified the optimal Dirichlet polynomial achieving the infimum d_N^2
- Assuming RH and a growth condition on zeta' at the zeros (sum_rho 1/|zeta'(rho)|^2 << T^{3/2 - delta}), the asymptotic constant matches Burnol's lower bound exactly
- This means the rate d_N^2 ~ C/log(N) is tight under these assumptions

### Numerical Status

The computational situation is challenging:
- d_N^2 decreases only as ~1/log(N), which is agonizingly slow
- Even at N = 20,000, the distance is still appreciably nonzero
- The convergence is consistent with RH but proving d_N^2 -> 0 computationally is infeasible (would need astronomically large N)
- A positive result: at least the first billion entries of a certain infinite triangular matrix associated with the criterion are all positive, which is consistent with RH

## 4. Connection to Our 2M Zeros

### What We Can Compute

Our dataset of ~2 million zeros of zeta on the critical line connects to Nyman-Beurling in several ways:

**4.1. The Burnol Constant C**

```
C = sum_{rho} 1/|rho|^2 = sum_{n} 1/(1/4 + gamma_n^2)
```

where gamma_n are the imaginary parts of the nontrivial zeros (rho = 1/2 + i*gamma_n). We can compute a partial sum of this using our 2M zeros. This constant controls the asymptotic rate of d_N^2.

**4.2. The Burnol Product**

Burnol showed that the projection norm (measuring how far chi is from B) equals:

```
product_{rho: Re(rho) > 1/2} |1 - 1/rho|
```

taken over zeros OFF the critical line. If RH is true, this product is empty (= 1) and the projection is perfect. Our verification that all 2M zeros lie on the critical line is consistent with this product being 1.

**4.3. Asymptotic Rate Verification**

Using our zeros, we can compute the expected asymptotic:
- Evaluate sum_{n=1}^{2M} 1/|rho_n|^2 to get a good approximation of C
- Compare to theoretical predictions for d_N^2 convergence rate

**4.4. The Gram Matrix**

The Nyman-Beurling optimization requires computing a Gram matrix whose entries involve:

```
<rho(theta_j/t), rho(theta_k/t)>_{L^2}
```

These inner products can be expressed in terms of the zeta function evaluated at various points, which connects back to the zero distribution. Our zero data could inform the spectral properties of this Gram matrix.

### Concrete Computations to Do

1. **Compute partial Burnol constant**: Sum 1/(1/4 + gamma_n^2) over our 2M zeros
2. **Estimate tail contribution**: Use zero density estimates to bound the remainder
3. **Gram matrix experiments**: For small N, compute d_N^2 using the Dirichlet polynomial formulation and compare with theoretical predictions
4. **Verify positivity**: Check that the relevant matrix entries are positive (extending the billion-entry verification)

## 5. Burnol's Contributions

### Key Papers

1. **"On an analytic estimate in the theory of the Riemann zeta function and a theorem of Baez-Duarte" (2002)**

2. **"A general strong Nyman-Beurling criterion for the Riemann Hypothesis" (2005)** (Note: This is actually by Baez-Duarte, but Burnol's work is foundational to it)

### Main Results

**The Projection Formula:**

Burnol showed that if N_B denotes the Nyman-Beurling subspace and P is the orthogonal projection onto its closure, then:

```
||chi - P(chi)||^2 = product_{rho: Re(rho) > 1/2} |1 - 1/rho|^2
```

This is remarkable: the L^2 approximation error equals a product over the "bad" zeros (those off the critical line). If RH holds, there are no such zeros and the error is zero.

**The Lower Bound:**

Burnol proved that d_N^2 >= (C + o(1)) / log(N), matching the Baez-Duarte et al. lower bound and establishing its sharpness. The constant:

```
C = sum_{rho on critical line} 1/|rho|^2
```

**Co-Poisson Transform:**

Burnol developed a framework using the co-Poisson transform, which gives a "de Branges space" perspective on the criterion. The co-Poisson transform sends a function f to:

```
g(x) = sum_{n=1}^{inf} f(nx) - (1/x) * integral_0^{inf} f(t) dt
```

This connects the Nyman-Beurling criterion to de Branges's theory of Hilbert spaces of entire functions, providing yet another angle of attack.

## 6. Current State and Obstacles

### What Has Been Achieved

1. **Equivalence established**: RH <=> d_N^2 -> 0 (proved unconditionally)
2. **Rate bounded**: d_N^2 >= C/log(N) (unconditional lower bound)
3. **Rate conjectured**: d_N^2 ~ C/log(N) under RH (conditional)
4. **Optimal polynomials identified**: Bettin-Conrey-Farmer found the minimizers
5. **Numerical evidence**: Computations up to N ~ 20,000 are consistent with RH
6. **Matrix positivity**: First billion entries of key triangular matrix are positive

### Recent Activity (2024-2025)

- **June 2025 preprint**: "Partitioning the Critical Strip" uses Nyman-Beurling to argue that hypothetical off-critical zeros would make d^2 strictly positive, contradicting the criterion. This attempts to close the gap but has not been verified/accepted.
- **2025 Gram matrix structure**: New work on polynomial decay of off-diagonal Gram matrix entries via Mellin smoothing and ladder parameterization.
- **Generalized criteria**: Extensions to L-functions beyond the Riemann zeta function.

### Specific Obstacles

1. **Logarithmic convergence**: d_N^2 ~ 1/log(N) is incredibly slow. Even proving the limit is zero requires understanding the behavior for ALL N, not just computed values. No finite computation suffices.

2. **The approximation gap**: We know d_N^2 >= C/log(N). To prove RH via this route, we need to show d_N^2 <= something/log(N) that also goes to zero. The upper bound is the hard part.

3. **Gram matrix explosion**: The Gram matrix for the optimization grows with N and becomes increasingly ill-conditioned. Numerical methods break down for large N.

4. **No structural control**: We lack a way to characterize the optimal Dirichlet polynomial coefficients a_n in closed form (except conditionally on RH).

5. **Circular dependence**: The sharpest results about the convergence rate require assuming RH, creating a circularity that must be broken.

## 7. Comparison: Nyman-Beurling vs. Hilbert-Polya

| Aspect | Nyman-Beurling | Hilbert-Polya |
|--------|---------------|---------------|
| **Nature** | Approximation/density in Hilbert space | Spectral theory of operators |
| **RH equivalent** | chi in closure of B | Zeros = eigenvalues of self-adjoint operator |
| **Key object** | Dirichlet polynomials, Gram matrices | Self-adjoint operator on some Hilbert space |
| **Computational** | Can compute d_N^2 for finite N | Can compute eigenvalue statistics |
| **Our zeros useful?** | Yes: Burnol constant, rate verification | Yes: pair correlation, GUE statistics |
| **Main obstacle** | Proving d_N -> 0 (logarithmic rate) | Finding/constructing the operator |
| **Progress metric** | d_N^2 values getting smaller | Operator candidates being identified |
| **Amenable to computation?** | Partially (slow convergence kills it) | More so (spectral methods, random matrix) |
| **Maturity** | Well-understood equivalence, slow progress | More speculative but deeper connections |

### Assessment for Our Project

**Hilbert-Polya advantages:**
- Our 2M zeros directly inform the spectral statistics
- Random matrix theory connection is well-developed
- Eigenvalue repulsion patterns are computable and testable
- The Berry-Keating and Connes approaches give concrete operator candidates

**Nyman-Beurling advantages:**
- The equivalence is unconditional and exact (not conjectural)
- The problem is well-posed: minimize d_N^2
- It's a "clean" optimization problem in principle
- Burnol's formula directly connects approximation error to off-line zeros

**Recommendation:**
- Nyman-Beurling is better as a **theoretical backup** than a computational one
- The logarithmic convergence rate makes direct numerical attack futile
- However, computing the Burnol constant from our zeros is a worthwhile exercise
- The Gram matrix structure could reveal patterns our neural networks might detect
- If our operator search stalls, the Nyman-Beurling framework gives us a different mathematical language to explore the same problem
