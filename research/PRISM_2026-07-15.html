01 · Frame

Invert the problem before generating a single idea

The one law: diverge fully before converging at all. Six ways of turning the problem over, each aimed at where the obstruction map already says the wall actually is.

  1. 01

    Where does the obstruction actually live?

    Not local or pointwise — routes 2–4 already proved that. It's a global Diophantine constraint: the autocorrelation of a test function cannot spike at every {log p} simultaneously. Reframe RH as an extremal problem over which functions can't do that — the exact shape solved by LP/SDP duality elsewhere in math.

  2. 02

    What would force a violation to reveal itself?

    An off-line zero would make τ_N go negative for some finite N and some g. Stop waiting for N→∞ and confirming positivity — actively hunt the g that makes τ_N most negative, and watch whether that minimum is converging to 0⁻ or drifting away as N grows.

  3. 03

    How would a hostile prime distribution lean?

    Diamond–Montgomery–Vorhauer and others built real Beurling generalized-number systems, same density as the primes, where the RH-analogue is provably false. Feed connes_decisive_v3.py one of those instead of true primes and watch it break — the diff is the hidden assumption.

  4. 04

    Who already solved this, in a different language?

    Weil and Deligne proved the RH-analogue for curves over finite fields, via étale cohomology and Frobenius eigenvalues. That's the same positivity statement, solved, in a parallel universe. The dictionary breaks down somewhere for Spec(Z) — find exactly where.

  5. 05

    Pre-mortem: it's 2036 and it's still open. Why?

    Likely answer: every attempt stayed inside the same explicit-formula basis. LEDGER already flags Li/NB/Jensen/de Branges as "same wall, different basis," closed 2026-05-19. The failure mode is re-coordinatizing, not changing the category of object — function → operator → cohomology → dynamical system → physical experiment.

  6. 06

    Strip it to the pure problem.

    An explicit infinite quadratic form must be positive semidefinite against a discrete adversarial set of directions (the primes). Other fields solve exactly this shape: LP/SDP duality (sphere packing, coding theory), free-probability universality proofs, Positivstellensatz/SOS certificates. None of routes 2–6 borrowed that machinery directly — only classical analytic number theory tools were tried.

02 · Diverge — figure panel

Twelve maximally unlike minds, each naming a mechanism

Blind to each other. Each names one mechanism for attacking RH from their own field's toolkit — independent convergence on the same idea is signal, not coincidence.

Sphere packer

The magic-function hunter

Treat Weil's criterion exactly like the sphere-packing LP bound. Hunt a bandlimited g built from modular/quasimodular forms that makes A+B−P touch zero exactly at the critical configuration — the way Viazovska's function made the LP bound tight in dimensions 8 and 24.

Lineage: Cohn–Elkies, Viazovska
Function-field traveler

The dictionary builder

RH is a theorem for curves over finite fields. Build the precise dictionary — zeta↔ζ(s), Frobenius eigenvalues↔zeros, étale H¹↔the missing Hilbert–Pólya space — and find exactly where it breaks for Spec(Z). The break point is the obstruction, in vocabulary that already has a solved analogue.

Weil, Deligne (proved for function fields)
Non-Hermitian physicist

The PT-symmetry advocate

Drop the requirement that H be self-adjoint. PT-symmetric (parity-time) non-Hermitian operators can carry entirely real spectra. A specific PT-symmetric deformation of Berry–Keating's H=xp has been proposed with spectrum conjectured to be exactly the zeros.

Bender, Brody, Müller (2017)
The Beurling adversary

The counterexample smuggler

Real generalized-prime systems exist, same density as the primes, where the RH-analogue is false. Run the existing operator code on one and diff it against the real-prime run, line by line, to isolate the exact numeric signature that "these are the real primes" supplies.

Diamond–Montgomery–Vorhauer counterexamples
Free probabilist

The local-law importer

GUE universality for random matrices isn't proved via any explicit-formula positivity — it's proved via a local law: eigenvalue rigidity down to the optimal scale, via a self-consistent equation plus high-moment estimates. Recast the prime-comb-vs-archimedean question as a local-law statement and import that machinery wholesale.

Erdős–Yau rigidity program
Cohomologist / topos builder

The Spec(Z) geometer

The live research program for a Weil-conjectures-style cohomological proof of RH over Spec(Z) — the arithmetic site / scaling site, or Deninger's conjectural foliated dynamical system whose periodic orbits are the primes. Deep-read for one concrete, checkable prediction to test against our own operator numerics.

Connes–Consani, Deninger
Statistical mechanic

The Lee–Yang analogist

Lee–Yang proves zeros of a physical partition function lie on a specific curve for a broad class of ferromagnetic models — a real, proven "zeros on a line" theorem via correlation inequalities. Is ζ, or τ_N, a limit of some statistical-mechanical partition function amenable to that style of argument?

Lee–Yang theorem, 1952
Automated prover

The bounded-target hunter

Don't aim automated theorem search at RH. Aim it at the narrow, checkable lemma: "τ_N ⪰ 0 for finite N is provable by an explicit SOS certificate of degree ≤ D." That's a formally verifiable, finite target — exactly what RL-guided proof search is built for.

AlphaProof-style bounded search, Lean/Mathlib
ML pattern-finder

The attribution miner

The actual DeepMind method that produced a new knot-theory formula: generate invariants, train a model to predict one from another, then read the trained model's attributions. We already have Keiper–Li λ_n to n≈2M and GORZ a[n] to n=80 — apply verbatim.

Davies et al., "Advantage of ML for mathematical discovery" (2021)
Quantum simulator

The scale-breaker

Build τ_N (or a Hilbert–Pólya candidate) as a tensor-network ansatz (MPS/DMRG) instead of a dense matrix. Olympus's dense-linear-algebra timing law is ~N^2.2; a tensor-network approach could plausibly reach N in the 10⁵–10⁶ range where the "misses near the ceiling" boundary effect fully resolves.

Quantum-inspired classical emulation
Skip-tracer

The forensic auditor

Assume our own construction is secretly circular somewhere — LEDGER already caught exactly this once (the sensitivity/perturbation route, retracted 2026-07-12). Make the audit a standing role, not a one-time check: where, precisely, does connes_decisive_v3.py implicitly assume something equivalent to RH?

Internal — apply forensic instinct inward
The 5-year-old

"Why not just check enough of them?"

Taken seriously, this restates the one non-circular partial handle that already works — verification height, n ≲ 2π·T. Its sane cousin isn't a joke: push T as far as rigorous (not floating-point) arithmetic allows, because every unit of T directly buys more unconditional n.

Already the project's strongest unconditional result
03 · Diverge — technique deck

Nine generic moves, run against the specific operator

SCAMPER-style techniques, each landed on the actual project state — not abstractly.

MoveApplied to RH
SubstituteSwap ζ(s) for a Dirichlet L-function or function-field zeta with a known proof; transplant the exact positivity argument back and find the one step that doesn't transplant. That non-transplanting step is the obstruction, made concrete instead of abstract.
CombineFeed connes_decisive_v3.py's finite-N output into an off-the-shelf SDP/SOS solver (cvxpy+SCS, SumOfSquares.jl) and extract an explicit sum-of-squares certificate of τ_N ⪰ 0. Patterned SOS coefficients across increasing N sometimes reveal the general formula by inspection.
AdaptAdapt sphere-packing LP-duality's "magic function" methodology directly, and Delsarte-style LP bounds from coding theory — another positivity-against-a-discrete-set problem with mature duality theory neither borrowed from before.
ReverseInstead of confirming positivity, build an adversarial optimizer that actively searches for the most negative achievable τ_N (over test functions, and over Beurling combs). Track whether the achieved minimum shrinks toward 0⁻ or grows with N.
Analogical transferSelberg's trace formula already makes primes↔closed geodesics on a hyperbolic surface rigorous. Build a concrete hyperbolic surface or quantum graph whose length spectrum is engineered to match {log p}; its Laplacian eigenvalues are proven real — study whether its positivity technique transfers.
10×/10÷Find the smallest nontrivial case where an analogous finite-N positivity is proven, not merely verified (small-conductor Dirichlet L-function, restricted-degree elliptic curve L-function) — reverse-engineer which technique made that case rigorous, then ask why it doesn't scale.
Constraint-breakDrop "the operator is a fixed N-independent object." What if the correct Hilbert–Pólya operator is only well-defined as an inductive limit, and positivity is a colimit-level statement? Reframes "gap converges but doesn't vanish" as possibly the correct terminal statement, not an artifact.
Combine two dead endsRoute 1 (Hankel/moment, dead — λ_n is log-concave) + route 5 (operator/tau, hits wall). Log-concavity is itself a structured signature — of a determinantal point process, not a classical moment sequence. Is (λ_n) provably a DPP? That has its own, viable, positivity machinery.
Follow the residueThe 23-dim near-kernel and the frozen eigenvalue at 1.82974 are oddly specific numbers, stable across independent sweeps. Treat them as signal: search whether either is recognizable elsewhere (a special zeta value, an OEIS entry, a dimension count in a related moduli problem).
