METHOD: LINEAR PROGRAMMING FORMULATION
================================================================================

1. Reformulation:
   min ∫ S·g over g ≥ 0, g band-limited to 4W, ∫ g = 1

   If min > 0, positivity is proven.

2. Discretization:
   - Basis: Fejer kernels F_c(r) = (sin(W(r-c))/(W(r-c)))²
   - Property: F_c ≥ 0, band-limited to 4W, integral = known
   - Centers: c₁, c₂, ..., c_N equally spaced in [a,b]
   - N chosen as 85% of capacity ≈ 0.85 × (b-a) × 2W/π

3. LP Setup:
   min c^T x
   s.t. A_eq x = b_eq, x ≥ 0

   where:
   - c_j = ∫ S(r) F_j(r) dr (cost vector)
   - A_eq = [∫ F₁, ∫ F₂, ..., ∫ F_N] (normalization)
   - b_eq = [1.0] (∫ g must equal 1)

4. Solver:
   scipy.optimize.linprog(c, A_eq, b_eq, bounds, method='highs')

   Result: optimal coefficients x*, LP minimum value = solution

5. Validation:
   - Binary search to find threshold where LP min crosses zero
   - Verify across multiple (window, height) pairs

   The window size is typically 30. Critical sampling is reached when
   the number of zeros falls to ~N_cap ≈ 0.75 × window_size × 2W/π.

   This structural point is HEIGHT-INDEPENDENT because it's a ratio
   (window size : zero spacing), not an absolute frequency.

   The Fejer kernel has specific band-limiting and orthogonality properties.
   The Weil symbol S = arch - prime has the archimedean floor, which is
   WINDOW-INVARIANT (§816) and grows slowly with height (~ln t).

   4W, the baseline Fejer discretization meets these oscillations in a way
