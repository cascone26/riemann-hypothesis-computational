# Resonance Map Analysis

## Key Finding

Deep minima in the Connes-τ operator (λ_min ≈ 0) correlate with
lsq values where γ_k × ln(lsq)/(2π) is near an INTEGER for some zero γ_k.

This is the MODE-ALIGNMENT condition: zero γ_k aligns with sinc mode n
when the mode frequency 2πn/L = γ_k, i.e., n = γ_k × L/(2π).

## Implications

1. SINGLE-ZERO resonances: γ_k² is the lsq where γ_k aligns with the mode
   n = γ_k × ln(γ_k²)/(2π) = γ_k × 2ln(γ_k)/(2π)

2. MULTI-ZERO resonances: when multiple zeros simultaneously align with modes,
   their contributions to P interfere constructively in the null space,
   creating even deeper minima than single-zero resonances.

3. The deepest minimum observed (γ₃, lsq=625: lam0=-1.65e-12) corresponds to
   γ₃ being especially near an integer mode at L=ln(625).

## The Deeper Story

The Connes-Weil operator has a null space whenever ALL the prime-sum terms P
exactly cancel A+B in the low-frequency modes. This perfect cancellation
requires the Riemann zeros to be EXACTLY on the critical line (RH).

At specific lsq values (resonances), a FEW zeros dominate the cancellation
because their modes are near-resonant. This makes the test MUCH more sensitive:
the sub-cancel metric sc drops by orders of magnitude at resonance lsq values,
making RH violations (if any) detectable with smaller matrices.
